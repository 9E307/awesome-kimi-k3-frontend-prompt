# 标题
陀飞轮手表机芯

## 演示链接
https://tourbillon-watch-movement.ok.kimi.link

## 提示词
把一只陀飞轮机械表机芯做成 three.js 交互网页：爆炸拆解图 + 真实运转的机械动画。
1. 模型：真实 CAD 装配体转换（Thingiverse 模型，CC BY 3.0，需署名），48 个零件；Blender 无头管线：零件拆分、语义命名、减面、PBR 材质（拉丝钢夹板、黄铜齿轮、蓝钢螺丝、红宝石轴承），记录每个齿轮的旋转轴心，导出 GLB + parts_map.json（零件中英文名+功能说明）。
2. 爆炸图：滑杆连续控制 0→100%，爆炸偏移叠加在装配基准位置上，禁止覆盖（会塌缩穿插）；同轴轮系分层展开不穿插。
3. 运转动画：主时钟驱动——齿轮系按真实传动比从发条盒到擒纵轮逐级加速（spin），摆轮游丝往复振荡（osc），擒纵叉快速步进+停驻（step，滴答机械感的灵魂），陀飞轮框架整体公转；支持暂停、定格任意时刻、调节转速。
4. 交互：点选零件显示名称/功能信息卡，子系统（轮系/擒纵/陀飞轮）筛选显示，轨道相机。
5. 验收：多角度截图自检 + 动画角度数值校验（用定格时刻读取角度，规避采样混叠）。
