# 标题
第一人称3D台球

## 演示链接
https://club-no9-billiards.ok.kimi.link/

## 提示词
用 Three.js + Rapier（@dimforge/rapier3d-compat）做一个纯静态、无构建步骤的第一人称物理台球网页游戏「九号俱乐部 CLUB No.9」，中文界面（中英双语切换），桌面端键鼠操作，触屏自动进入观战模式。
要求：
场景：加载 Sketchfab 酒吧模型 Bar Diorama 作为球房（隐藏其自带球桌），Poly Haven 胡桃木贴图做库边/球杆木饰面，fireplace HDRI 做环境反射；呢绒、球面号码、地板等其余纹理全部用 Canvas 程序化生成（确定性 PRNG，每次加载一致）。
台球玩法：Rapier 刚体物理，57.2mm 标准球，按模型库边拟合台面；第一人称行走模式（WASD）+ E 俯身瞄准；左键蓄力、滚轮调力度、空格出杆；A/D 加塞、W/S 高低杆、R 复位杆法；F 摆自由球、T 重新摆球、G 切比赛/练习；辅助瞄准线可开关。物理核心（sim.js）与渲染（world.js）分离：物理是唯一事实源，渲染只读不写，且物理核心不依赖 DOM、可在 Node 跑测试。
规则：本地双人简化中式八球（开球后首个进球定组、黑八决胜、犯规判自由球），另有自由练习模式；记分牌、连击火焰、成就徽章、进球特写镜头（可关）。
回放系统：每杆可回放（V），时间轴拖动 + 0.1×–1× 变速。
酒吧小游戏（道具常驻场景、走近触发）：飞镖（标准 20 分区镖盘、弹道求解器、三镖一轮、180 徽章）、骰盅比大小（真实骰盅模型 + 独立 Rapier 小世界摇骰）、威士忌倒酒、俄罗斯轮盘（左轮模型）。
音频：Freesound 社区 CC0 真实台球采样（球碰/库边/落袋/开球/摆球/欢呼，多切片变体随机）+ Web Audio 程序化房间混响（噪声衰减生成 IR）与压限；用户提供 lounge jazz 循环 BGM，M 静音。
工程：import map 引 three/rapier；i18n 字典驱动全部文案；设置面板（语言/进球特写/瞄准线）与「关于·开源材质与许可」署名面板；test/ 下物理、飞镖、酒吧逻辑三组 Node 测试。
