# 标题
月球基地模拟

## 演示链接
https://ayb7ngjjg6wl2.ok.kimi.link/

## 提示词
用 three.js 做一个"月球基地分阶段建设"概念网页，全部程序化建模（不用外部模型文件），硬性标准：电影级场景，总三角面 ≥ 300 万，对标 NASA 概念渲染图。
本版核心：建设阶段时间轴——阶段1 着陆器降落（月尘被发动机吹起）→ 阶段2 太阳能阵列展开 → 阶段3 圆柱舱吊装连接 → 阶段4 穹顶主舱框架搭建与封闭 → 阶段5 月球车驶出、基地灯火通明投入运营；拖动时间轴可正放倒放，建造过程是实体拼装动画，不是渐隐切换。
建模不缩水：穹顶框架逐根、舱门舷窗扶手、电池片逐格、月球车悬架轮组、着陆器喷口坡道；月面 2~3 个环形山，月壤置换颗粒与车辙；PBR 全套，金属磨损月尘覆盖、铝箔皱褶反光，禁止卡通感。
验收：60fps（合并几何/实例化/LOD，不许肉眼降质）、控制台零报错；自己截图检查各阶段拼装动画无穿模，至少迭代 3 轮，不满意就修复后重新验收。
交付：一个自包含所有资源、模型、贴图、代码等、可用于直接部署上线的代码包，放入 /output（assets 放 /output/assets）。

追加硬性要求（2026-09-11 第二版）：
1) 页面必须内置中英文一键切换：所有 UI 文案、按钮、信息卡、介绍牌全部双语，默认中文；
2) 重点打磨以下维度并逐项截图自检：模型物件之间不得穿插/穿模（含动画全过程）；细节要有惊喜感（彩蛋级微细节，如铭牌、编号、指示灯）；材质质感与体积感必须厚重真实；动态与特效（粒子、辉光、运镜）要电影级；UI 设计要精致（排版、留白、层级、暗色专业风）。
