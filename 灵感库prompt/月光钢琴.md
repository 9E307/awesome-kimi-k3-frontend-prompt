# 标题
月光钢琴

## 演示链接
https://fpiqqnhozwzso.ok.kimi.link

## 提示词
制作一个可演奏的三维月光钢琴网页：黑色星空与巨大月球前，一架白色三角钢琴和琴凳置于悬浮平台上，灯光冷静、构图简洁。点击钢琴后进入第一人称琴位，88 个琴键均可弹奏，使用 Web Audio 实时合成音色，并让琴键按下与回弹同步响应。支持鼠标点击、按住滑动连奏，以及键盘演奏：Q–P 对应左手音区，A–L、分号和单引号对应右手音区，1–0 对应黑键；持续显示简洁映射提示，Esc 退出琴位。提供可选的手势演奏入口，只有用户主动开启并允许摄像头后才启用，未开启时键鼠仍完整可用。保持音乐反馈及时、相机过渡平滑，呈现安静的月夜演奏氛围。
