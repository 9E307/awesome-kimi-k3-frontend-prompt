# 标题
古灵阁灯光控制台

## 演示链接

## 提示词
角色与目标
你是一名同时精通 Blender（bpy 脚本）与现代 Web 3D（Three.js）的技术美术。请在本机 Blender 中用程序化建模搭建一座 LEGO 风格的古灵阁巫师银行（Gringotts Wizarding Bank），完成做旧材质与三种灯光氛围的渲染，并最终交付一个可在浏览器中实时调节灯光氛围与细节的互动网页控制台。
全程要求：所有产出保存到当前工作区；每一步渲染结果必须打开检查、发现问题即迭代修正；网页交付前必须在真实/无头浏览器中实际打开验证，且不得残留后台服务进程。
参考氛围（两张参考图）
造型参考：LEGO 76417 古灵阁套装官图 —— 白色大理石立面 + 门廊圆柱 + 「GRINGOTTS BANK」招牌 + 绿色穹顶 + 顶部乌克兰铁腹龙 + 下方岩柱支撑的地下金库与矿车轨道。
氛围参考：古灵阁大理石大厅概念图 —— 做旧暗色大理石、金饰、水晶吊灯暖金顶光、圆窗冷色光束、烛光点点、强烈明暗对比与体积光。
第一部分：场景搭建（Blender bpy 脚本，后台模式 -b --python 运行）
比例约定：1 乐高单位 = 1 Blender 单位，凸点间距 1.6、凸点半径 0.45、凸点高 0.35。材质统一为乐高塑料感（Principled，Roughness≈0.28，Coat≈0.25）。
必须包含的结构：
银行本体：白色/浅灰大理石主楼（宽 22 × 高 15），立面横向砖纹线条；四根圆柱门廊（柱基+柱身+环箍+柱头）+ 门楣；内凹棕色双开大门 + 金色球形门把 + 白色门框；门上圆形气窗（金色十字棂）；「GRINGOTTS BANK」金色立体字招牌（位于内侧两根圆柱之间，避免遮挡）；两侧三层翼楼（带白色窗格、檐口、屋顶凸点）。
立面细节：两扇向外倾斜的黑框窗 + 黑色阳台栏杆；门口与翼楼墙面共 4 盏铸铁壁灯（自发光材质 LampGlow）。
穹顶塔楼：白色鼓座（8 扇小窗 + 檐口环）+ 绿色半球穹顶 + 金色肋条与尖顶球。
乌克兰铁腹龙：灰白身体趴在穹顶前沿，内外双片膜翼（带翼缘龙骨、翼指、翼钉）、金角金瞳、背刺、四肢抓握带金爪、尾巴缠住穹顶；口喷双层火焰（橙色外焰 FireOuter + 亮黄内焰 FireInner，自发光）；颈部到穹顶一条 9 节铁链。
左侧·魔法宠物店：深红店面 + 金色 MENAGERIE 招牌、绿色窗框、双坡灰屋顶、黑色四角尖塔、橙色烟囱 ×2。
右侧·附属小楼：两层米黄/白条纹墙、双坡屋顶、壁灯 ×2、屋顶小猫头鹰。
地下部分：层叠错动的岩石柱（三种灰色岩石材质）支撑平台；正面圆形金库大门（金色门盘 + 深灰辐条与门毂）；两段矿车轨道弧线（铁轨 + 枕木）+ 载金币的矿车；底层轨道环线 + 轨道支柱；倒挂石笋 ×8、平台下吊链 ×3、左侧吊臂悬挂笼式电梯；平台加宽并有岩石支撑。
氛围道具：门前四级台阶、两盏黑色铸铁路灯（LampGlow 自发光灯头）、门口金锭与金币堆、4 个乐高小人仔（妖精银行家、蓝袍巫师、绿袍巫师、戴帽守卫）。
地面：大平面（亮/暗渲染时切换颜色）。
相机：竖幅 620×800，50mm，3/4 前侧视角，取景须完整覆盖地面到龙翼顶端。
第二部分：材质做旧
对大理石、白砖、灰砖、三种岩石、穹顶绿、棕褐墙、龙身、龙翼共 10 种材质追加程序化做旧节点（不依赖 UV，用 Generated 坐标）：
Noise Texture（Scale 3.5–8，Detail 6，Roughness 0.75）→ ColorRamp（暗污渍色 ↔ 原底色）→ Mix(MULTIPLY, Factor 0.35–0.6) → Base Color，形成污渍与雨痕渗透。
第二个高频 Noise（Scale≈22）→ Map Range → Roughness（在原粗糙度 ±0.15/+0.45 间变化）。
做防重复叠加判断（节点已存在则跳过）。
第三部分：三种灯光氛围与渲染
同一相机下切换灯光组渲染三张 620×800 PNG（EEVEE，开 raytracing，AgX 中高对比）：
明亮版 gringotts_light.png：近白世界环境（强度≈0.45），暖白主光 DISK 面光 + 冷蓝补光 + 顶部轮廓光（能量 350–750），地面浅灰。产品摄影质感，白色区域不过曝、圆柱与立面有清晰明暗分界。
暗夜版 gringotts_dark.png：深蓝黑世界（强度≈0.85 的极暗蓝），冷蓝月光主光 + 弱冷补光 + 微弱暖色正面光；路灯/壁灯自发光提到 35–40 并配暖色点光；金库大门暖光、火焰点光。整体可读剪影 + 暖光点缀。
金色大厅版 gringotts_golden.png（对照氛围参考图）：暗暖世界 (0.035, 0.024, 0.012)；顶部强暖金面光（≈7000，色 1.0/0.74/0.38，模拟吊灯）+ 正面暖光 + 暖补光；两侧冷蓝 Spot 光柱（≈10000–14000）；大立方体 Principled Volume（Density≈0.0045，Anisotropy 0.35）制造可见光束；合成器 Glare（Fog Glow, Threshold 1.0, Size 0.7）加辉光；所有烛火/火焰点光打开。
注意 Blender 5.x 兼容性：合成器用 scene.compositing_node_group（节点组 API，Glare 的 Type 枚举为 'Fog Glow'）；新节点命名受语言影响，脚本开头设 use_translate_new_dataname = False 或按 n.type=='BSDF_PRINCIPLED' 查找节点。
第四部分：互动灯光控制台（网页）
技术栈：Vite + Three.js（npm run dev 可启动并转发 host/port 参数）。模型经 Blender glTF 导出为 GLB（仅网格，文字先转网格再导出）。另用 Python(PIL/numpy) 生成 512px 多倍频噪声做旧贴图 grunge.png（近白底 + 暗斑 + 垂直雨痕）。
页面功能（必须全部实现并验证）：
左侧毛玻璃控制面板，标题「古灵阁 · 灯光控制台」。
灯光氛围按钮 ×3：☀️ 明亮 / 🌙 暗夜 / 🏛️ 金色大厅 —— 分别对应第三部分的三套灯光参数（背景色、半球光、平行光/聚光颜色强度位置、雾色），金色大厅为默认。
机位按钮 ×4：全景 / 正立面 / 穹顶火龙 / 地下金库 —— 相机带缓动飞行切换（OrbitControls，阻尼开启）。
滑杆 ×4：🔥 火焰强度（Fire 材质 emissiveIntensity + 火焰点光）、🏮 灯火强度（LampGlow 材质 + 8 盏灯点光）、🌫️ 雾气浓度（FogExp2 密度随氛围缩放）、🕸️ 做旧程度（grunge 贴图作为 map 叠加 + 基色压暗 + 粗糙度提升，0 时完全移除）。
火焰与灯火带随机闪烁动画；自动旋转开关。
支持 URL 参数直达状态（?mood=night&cam=vault&fire=1.5）。
ACESFilmic 色调映射，页面深色 UI，无登录/权限门槛，首屏立即可交互。
验证：启动临时 dev server，用无头 Chrome（--use-angle=swiftshader）分别截图默认金色大厅、?mood=night&cam=vault、?mood=bright&cam=dragon 三种状态并目检确认渲染正确，验证后必须停止服务器，交付时给出 [http://localhost:7100/](http://localhost:7100/) 预览链接与项目绝对路径。
