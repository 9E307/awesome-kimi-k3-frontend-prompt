# 标题
透视火箭标注图

## 演示链接
https://yduqqbfiymi4u.ok.kimi.link/

## 提示词
用 three.js 做一个火箭/卫星结构件"工程蓝图"风格 3D 展示网页，所有模型代码程序化建模（不用外部模型文件），硬性标准：电影级精度，单场景 ≥ 300 万三角面。
建模（几何实体堆细节，禁止贴图冒充）：火箭一级段（9 台发动机喷口圆形布局、冷却通道逐条可见、栅格舵、着陆腿液压关节）、可分离整流罩（内壁加强框可见，内放卫星）、卫星（帆板电池片逐格、碟形天线镜面级细分），所有零件有真实厚度与机械连接关系。
本版核心视觉：蓝图工程图美学——深蓝背景 + 发光白/青色线框与实体混合渲染，每个零件带尺寸标注线、引线标签与技术参数（中文）；可一键切换"实体 PBR 模式 / 蓝图线框模式 / X 光剖视模式"三种视图，切换有平滑过渡。
实体模式下材质不缩水：PBR 全套，白漆磨损、隔热毯褶皱、喷口烧蚀。
交互：拖拽环绕、滚轮缩放；点击零件显示剖面与标注；一键爆炸视图/复位。
验收：60fps（合并几何/实例化/LOD，不许肉眼降质）、控制台零报错；自己起本地服务器截图放大检查三种视图与标注正确性，至少迭代 3 轮，不满意就修复后重新验收。
交付：一个自包含所有资源、模型、贴图、代码等、可用于直接部署上线的代码包，放入 /output（assets 放 /output/assets）。
