日落收藏家

## 提示词
请制作一个「日落收藏家 · 西向江景公寓」等距微缩公寓网页，以正交等距视角观看——不是透视，是模型盒式的等轴视角——整体像一个可以拖拽旋转、缩放的可收藏模型盒，没有任何 UI 元素。首屏是经典的等距角度：从公寓开口的一侧斜 45° 俯视，能同时看见室内全景和整面落地窗。首屏构图硬性要求：整面西向落地窗、窗外的落日与江面反射、以及斜射进室内的长条窗框光影必须在首屏画面里直视可见、占据视觉重心（参考 style_ref.png 的构图——落地窗正对观众，落日悬在城市天际线上，江面一条金色光路），观众第一眼就要被"golden hour 洒满小屋"的光影击中。
风格定义： 低多边形微缩模型风 + 细腻贴图：几何简洁、棱角分明、比例略 Q，但每个表面都有真实的材质细节——橡木地板纹理、亚麻沙发经纬、书脊纸面、陶盆釉面、金属吧凳。不要三渲二描边，不要写实 PBR 反光，不要塑料感。 氛围：安静、治愈、收藏家式的浪漫——这个房间的主人买房就是为了这扇窗的日落；每天 17:00 到 19:30 是这个家的黄金仪式。
户型结构： 一个高层公寓大开间（约 8×6 米、层高 3 米的尺度感），保留两面墙 + 地板的模型盒剖切，切口露出墙体断面。整面落地玻璃窗在西侧整面（从首屏等距视角直视可见，这是全场主角和构图锚点），窗外是三层纵深：近景江面（宽阔、反光）、中景城市天际线剪影（高低错落的楼宇、一座斜拉桥）、远景天空。地板是浅色橡木直拼，白墙，局部木饰面。
细节密度（硬性要求，以 style_ref.png 为及格线）： 每个表面都要有三层细节——远景可见的二级细节：书架上的书脊阵列、墙面挂画与照片、插座开关、窗帘（收在一边）、踢脚线、吧台上的瓶罐、绿植群落；点击聚焦后可见的三级细节：沙发亚麻经纬、书脊文字、唱片封面、杯底水渍、叶片脉络。墙面不允许大面积"空白光板"。零碎生活物摆到"有人真的住在这里看了一百次日落"的程度：书、唱片、咖啡杯、望远镜、相册、毯子。
陈设（按区域）：
观景区（落地窗前）：一张浅灰亚麻 L 型沙发正对窗 + 一张原木茶几（上面一本翻开的摄影集、一杯手冲咖啡冒着热气）+ 窗边立着一架黄铜望远镜（对准落日方向）——这是看日落的专属位置
书架墙（内侧整面）：顶天立地的原木书架，塞满书、黑胶唱片、几个小摆件（相机、干花、陶罐），一格藏着一串暖光小灯（亮着）
吧台角（另一侧）：原木吧台 + 两张金属吧凳，吧台上手冲咖啡器具一套、几颗水果，吊柜下暖光灯带（亮着）
绿植：窗边和书架顶部的盆栽群（琴叶榕、龟背竹、垂吊绿萝），夕阳把叶影投在墙上
地毯：沙发区一块米色羊毛地毯，夕阳在毯面上拉出长长的窗框光影
光照与氛围（这个 case 的核心，必须做出"眩晕瘫坐"感）： 一条连续的日落时间轴是全作的灵魂——太阳从 17:00 的淡金色高角度，缓慢下沉到 18:30 触及天际线的浓烈橙红，再到 19:00 日落后的蓝调时刻（天光变冷变蓝，城市灯火次第亮起），最后进入夜晚。拖动时间轴，一切联动：太阳位置与高度、阳光色温（淡金→金→橙→橙红）、天空渐变、室内长影的角度与颜色、江面反射的金色光路（随太阳位置移动、随天色变暗而消失）、城市窗户与路灯在蓝调时刻渐次点亮、室内灯在入夜后自动亮起（书架小灯、吧台灯带、落地灯）。阳光最浓的那几分钟，整个房间是熔金色的，地板上的窗框光影锐利清晰——这是全作最高光时刻。
材质（硬性要求）： 各处表面必须用生图贴图，不允许纯色糊过去：橡木地板、亚麻沙发、原木书架与吧台、羊毛地毯、陶盆、金属吧凳、书脊与唱片封面、摄影集内页。文字都要清晰不糊。江面用带反射的着色器/材质（反射太阳与天色），不允许纯色蓝面。
动效（持续、克制）： 江面微波粼粼；咖啡热气袅袅；绿萝垂叶极轻微摆动；入夜后城市灯光缓慢闪烁；书架小灯与灯带轻微呼吸。
镜头： 正交等距视角，可拖拽旋转（限制在能看清室内的角度范围内）、缩放；首屏是标准等距角度，默认时刻 18:10（日落最浓前）。
交互（要顺手又有仪式感）：
日落时间轴：按住画面拖动（或拖动时间轴）→ 手动 scrub 17:00–20:00 的连续日落，快进快退都丝滑；松手后从该时刻继续自动流转（自动流转速度：完整日落 120 秒一圈，循环播放）
点击聚焦：点任意主要物件（沙发观景区、书架墙、吧台、望远镜、绿植……）→ 镜头平滑拉近；点空白处或再点一次 → 回到全景
望远镜彩蛋：点望远镜 → 镜头短暂推到窗外落日特写 2 秒后收回（"透过它看了一眼"）
室内灯：点落地灯 → 手动开关所有室内灯（覆盖自动逻辑）
定格模式：点太阳 → 暂停时间流转（把日落"收藏"在当下这一刻）；再点恢复
默认状态：自动流转、18:10 起步、室内灯跟随天色自动
风格参考： 本文件夹 style_ref.png 是氛围参考图——构图（落地窗+落日江景正对观众）、金色光影、模型盒质感、细节密度全部以它为准（元素布局不必逐一对齐，陈设以本文描述为准）。如果对话中没有提供 style_ref.png，第一步先用生图技能按上面的风格定义与构图要求生成一张概念参考图给我确认，确认后再开工。自检时直接对照：首屏截图和 style_ref.png 并排看，密度感、光影感明显不如就继续加细节调灯光。
实现分工： 室内一切必须是 3D 实体；窗外江面/天际线/天空分层实现（近景江面 3D 水面 + 中景城市体块剪影 + 天空穹顶着色器渐变），不允许用一张平面背景图糊过去；太阳、光路、室内光影必须全联动。
流程（分件确认，每步等我确认后再继续）： 先分件做、各截一张图给我检查：① 户型结构 + 落地窗 + 江面天际线 + 18:10 的金色光影 ② 观景区与书架墙（光影要对、书脊要清）③ 吧台、绿植与零碎。我确认后再组装、补动效与交互、调日落时间轴全联动。
产物： 一个能直接部署打开的网页；另外五张定格大图（17:30 淡金 / 18:25 熔金最高光 / 18:50 橙红落日触线 / 19:10 蓝调时刻城市亮灯 / 点击聚焦到沙发观景区）。
视觉自检（硬性要求）： 过程必须包含视觉自检：截图自检、自己读图——①首屏构图：落地窗+落日是否直视可见、是否视觉重心；②细节密度：与 style_ref.png 并排对比；③日落三个阶段的色温光影各自成立、联动无穿帮；④窗框长影是否锐利、江面反射是否跟随太阳；⑤贴图细节、文字是否清晰。每个交互状态（聚焦 / 定格 / 望远镜 / 手动灯）都要截到，不满意就调整重来。
