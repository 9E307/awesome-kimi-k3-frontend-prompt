# 标题
机械臂工作流程看板

## 演示链接
https://armworks.ok.kimi.link/

## 提示词
用 three.js 做一个工业 HMI 风格的双机械臂工作单元 3D 模拟器网页（自包含、零 CDN、本地化 three.js，英文 UI）：安全围栏车间内（地面 CELL 07 / DUAL-ARM COOPERATION ZONE 标识、配电柜、波形屏），两台 KUKA 风格六轴机械臂在各自工位与传送带之间做取放交接（pick-and-place handover，含夹爪开合与运动轨迹残影）；深色工厂面板风 + 荧光黄绿点缀，顶部状态栏（SIMULATION / STATUS: RUNNING / SYSTEM LOAD 标签、红色 ESTOP、NIGHT/SETTINGS/LOGOUT 按钮），左右两侧各一块 AGENT 面板（J1 BASE / J2 SHOULDER / J3 ELBOW 角度仪表盘、扭矩实时曲线、手动/自动控制、TIME CONTROL、命令终端滚动日志），双臂任务协同动画循环播放且可手动接管单臂。
