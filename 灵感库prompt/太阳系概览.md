# 标题
太阳系概览

## 演示链接
https://solar-system-overview-web.ok.kimi.link/

## 提示词
请帮我完整实现一个"黑白像素风的交互式太阳系网站"（纯静态、可本地运行、可部署静态托管），以下是全部需求，按此执行并逐项验收。

【一、技术底线】
1. 纯静态站点：importmap + 原生 ESM，three.js 及全部依赖本地 vendor，零 CDN、零构建步骤、零后端；入口 index.html。
2. 双轨素材策略：几何用 three.js 内置球体/参数化网格；贴图使用真实天文影像（NASA Visible Earth、LRO 月图、SolarSystemScope），按 standard/高清 4K/极清 8K 三档组织，附纹理加载管理（Promise 缓存、SRGB/线性色彩空间区分、各向异性≤8、失败可重试且可降级到标准档）。
3. 渲染器：antialias、SRGB 输出、ACESFilmicToneMapping（曝光≈1.05）、DPR≤2（移动端≤1.5）、近平面 0.002、黑色场景背景。

【二、场景内容（全部实时 3D，禁止图片/视频冒充）】
1. 成员：太阳 + 八大行星 + 月球（潮汐锁定绕地球），行星公转内快外慢、自转按真实比例、轴倾角真实（土星 27°、天王星 82°）。
2. 太阳：自发光球体 + 微弱光晕；点光源照明 + 微弱环境光。
3. 地球：昼/夜双贴图按"法线·太阳方向点积"实时切换（晨昏线过渡），夜面城市灯光自发光（独立开关）；独立云层壳（1.006R、alphaMap）与大气菲涅尔边缘光壳（1.025R、乘日照系数）——三层均可单独开关。
4. 土星：球体与光环同处 27° 倾斜组，环为 XZ 平面参数化网格、UV 按半径映射长条纹理、双面、alphaTest≈0.04、depthWrite=false。
5. 月球：8K 月面贴图（网页端给 4K/8K 两档），近景光照需压暗至中灰真实质感。
6. 背景：稀疏固定星点（非大面积星云贴图）。

【三、交互系统】
1. 天体选择：目录点击 / 场景射线点击（小天体带放大隐形点选球）/ 上一颗·下一颗循环。
2. 聚焦相机：相机持续锁定运动中的目标天体（每帧同步平移），永远不会被公转带跑；取距 = 包围半径/视角填充系数（默认 0.7、月球 0.78、太阳 0.45 带黑边）；850ms ease-out 平滑过渡且过渡中实时跟踪目标；用户拖动立即接管（取消程序镜头）。
3. 观察预设：受光面 / 明暗交界 / 极区 / 临边 / 夜侧 / 细节 六类机位（按"指向太阳方向 × 侧向 × 上"组合偏移；目标在原点时用固定方向防零向量退化）。
4. 时间与显示：全部暂停、独立自转开关、独立公转开关、0–4× 速度、轨道线开关、标签开关、重置视角；自转/公转状态与 UI 严格同步。

【四、黑白像素风 UI（参考 [careers.kimi.com](http://careers.kimi.com) 气质，纯黑白灰、无蓝色）】
1. 等宽字体为主，数字/短标题/导航用像素字体（OFL 授权并本地化）；中文正文用清晰正文字体。
2. 顶栏：左侧 SOLAR SYSTEM/太阳系标识，右侧「总览 / 天体 / 显示设置」。
3. 天体选择器：按恒星/行星/卫星分组、两位数编号、当前项高亮（不用大色块）、可滚动。
4. 左下铭牌：编号(如 05/10) + 大标题(中文名+英文) + 类型标签 + 一句诗意介绍 + 直径数据 + 「查看详情↗」；总览态显示"尺寸与距离经过展示性调整"。
5. 底部工具栏：暂停/自转/公转/速度/轨道线/重置视角（图标+短文本）+ 上一颗/下一颗步进器（中间显示当前天体英文）。
6. 详情面板（右滑出）：简介、关键事实（带单位与"约"标注）、观察重点按钮（每个都绑定真实相机/图层状态并显示"当前"）、资料来源、更多资料链接；设置面板分「观察/画质」两组。
7. 事件穿透：全屏 UI 层 pointer-events:none，仅按钮/列表/面板/工具栏 auto；面板内滚动不传给画布。

【五、像素化开场与动效】
1. 开场：全屏 1-bit Bayer 有序抖动月面（图像采样→灰阶量化→4 级灰阶→4×4 矩阵），抖动色块随加载进度从 14px 平滑锐化到 1.5px（进度即加载指示），中央像素字标题+暗色径向遮罩+「开始探索 →」按钮；必须用户点击才进入（禁止自动进入）。
2. 退场：点击后标题 220ms 淡出，随后数字矩阵波动式消散——斜向波前扫过（带单元格微扰），像素块随波动梯度缩小淡出，约 800ms 后进入太阳系总览。
3. 其余动效：切换天体时大标题与诗句乱码解码落定（约 320/420ms）；导航按钮字符双层滚动（350ms、每字符 30ms 错峰、悬停与聚焦均可触发）；面板 opacity+12px 位移过渡（约 220ms）；详情面板标题局部像素揭示（稀疏方块遮罩≤700ms）。
4. prefers-reduced-motion 下全部退化为直接切换。

【六、信息增强件】
1. 观测十字线：鼠标细十字跟随，右上实时显示所指星球表面 LAT/LON 经纬度（触屏隐藏）。
2. 目录悬停预览卡（名称/直径/距日/诗句）。
3. 键盘全操控：←/→ 切星、↑/↓ 推拉、空格暂停、1–0 直达、O 总览、D 详情、S 设置、H 快捷键卡、Esc 关面板。
4. 观测日志：右下角等宽小字滚动记录最近 3 条操作。

【七、移动端与可访问性】
1. 目录横向滚动、选中项自动进入视野；详情/设置为可关闭底部面板；触控点按区 ≥44px；安全区适配；工具栏与面板互不遮挡。
2. 语义化按钮、aria-pressed/aria-selected 正确、焦点可见、Escape 关闭面板并焦点返回触发按钮、加载状态用轻量 live region。

【八、验收标准（逐项实测）】
1. 启动即见像素开场，点击后波动消散进入总览（太阳居中、轨道线、行星标签）。
2. 十个天体逐一切换：名称/目录选中/资料同步、镜头平滑跟踪不丢、无黑球、无 shader 编译错误、无 404。
3. 地球三层开关可见效果、土星环与赤道共面、月球晨昏线自然且不泛白、太阳为带黑边圆盘（非满屏日面）。
4. 桌面 1440×900 与手机 390×844 截图核对无遮挡无溢出；控制台零错误；减少动态效果设置下可直接使用。
