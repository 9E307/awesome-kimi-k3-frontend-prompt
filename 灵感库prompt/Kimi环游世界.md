# 标题
Kimi环游世界

## 演示链接
https://512z.github.io/kimi-around-the-world/

## 提示词
请制作一个完整可玩的单人浏览器游戏合集 KIMI AROUND THE WORLD。玩家从月球大厅进入三个主题游戏，与三名 NPC Kimi 一起旅行、竞赛和战斗。每个游戏都应具有完整流程，而不只是视觉演示。
角色与月球大厅
Kimi 是一个小球角色，带两只白色竖向胶囊形眼睛。玩家与三名 NPC 使用不同颜色和名字，保持统一、简洁的角色风格。
月球大厅包含起伏地形、可探索的基地设施、黑色天空和远处悬挂的地球。玩家可自由滚动探索，NPC 在基地内活动。通过游戏选择入口进入以下三个游戏，并保留玩家和 NPC 的名字、颜色。游戏结束后可返回月球大厅。
游戏一：MOON RACE
制作月球悬浮赛车游戏，在约 8.8 公里的环形陨石坑赛道上与三名 NPC 竞速。
提供加速、转向、刹车及追随镜头，驾驶反馈明确。
完整实现起跑倒计时、检查点、圈数、排名、完赛和结果页。
布置道具箱，提供火箭、香蕉皮等进攻或干扰道具，并给予明显的命中反馈。
NPC 使用实际驾驶逻辑完成比赛，能沿赛道行驶并参与竞争。
赛道具备月面地形、弯道、高低变化和清晰边界，镜头不穿地形。
游戏二：VENICE SPEED
制作晨光中的威尼斯运河游戏，玩家驾驶贡多拉穿过水道、建筑和桥梁。
场景包含有层次的沿岸建筑、码头、桥梁和水面反射。
贡多拉具有划桨动作、转向惯性和速度反馈。
提供两种玩法：接送乘客的单人航行，以及与三名 NPC 进行的水上竞速。
竞速模式包含道具箱和水上恶作剧道具，支持干扰对手并显示效果。
完整实现任务或比赛开始、过程反馈、结束结算和重新开始。
避免船体、相机穿入岸边建筑，并正确处理水面反射。
游戏三：CYBER SPACESHIP
制作雨夜霓虹城市中的飞行出租车游戏。城市具有高楼、空中连廊、广告牌、交通流、雨雾和灯光层次，飞行器及角色由程序生成。
提供两种模式：
追逐模式
玩家驾驶飞行出租车，在城市峡谷中躲避建筑与追捕者。
鼠标控制飞行方向，W/S 调节速度，Shift 加速，空格进行向上突进。
加速会积累热量，过热后短暂限制使用。
沿途出现封锁墙，玩家必须穿过逐渐缩小的缺口。
每突破一次封锁，追捕增强、可飞行高度下降。
根据距离、近距离擦过障碍和突破封锁计分，撞毁后显示结果并支持重开。
空战模式
玩家与三名 NPC 在循环城市空间中进行三分钟战斗。
可射击、拾取道具并使用冲击波、EMP、护盾和冲刺。
被击中会短暂失控，撞击城市建筑后爆炸并重生。
NPC 能追踪目标、躲避障碍、射击和使用道具。
提供计时、命中数、战斗记录和最终排名；循环场景接缝应不可察觉。
技术与整体体验
使用原生 JavaScript 和 Three.js 0.169.0 ES Modules，无框架、无构建步骤、无后端或联网对战，可直接通过静态文件服务器运行。
所有角色、载具和建筑通过基础几何体或自定义几何体生成；纹理使用 Canvas 或 Shader，不使用外部模型和图片贴图。
各游戏可从大厅启动，也能独立打开；独立打开时具备自己的菜单与完整游玩流程。
统一采用简洁科幻界面、Geist Mono 字体、蓝色强调色、左侧菜单和实时运行的背景场景。
提供操作说明、暂停、画质与声音设置、HUD、音效、结果页和本地最佳成绩保存。
页面失去焦点时暂停，菜单操作不得误触游戏控制。
最终交付完整静态网站源码，并实际验证所有游戏的进入、游玩、结算、重开和返回流程。确保无控制台报错、无明显穿模或场景跳变，以普通笔记本默认画质下流畅运行为目标。
