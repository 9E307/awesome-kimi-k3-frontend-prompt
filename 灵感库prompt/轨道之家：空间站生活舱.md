# 轨道之家 · 空间站生活舱 — Roll Prompt（中文版）

请制作一个「轨道之家 · 空间站生活舱」等距微缩舱段网页，以正交等距视角观看——不是透视，是模型盒式的等轴视角——整体像一个可以拖拽旋转、缩放的可收藏模型盒，没有任何 UI 元素。首屏是经典的等距角度：从舱段开口的一侧斜 45° 俯视，能同时看见弧形舱壁内侧和整块舱内地板。**首屏构图硬性要求：大圆形舷窗和舷窗里的地球必须在首屏画面里直视可见、占据视觉重心**（参考 style_ref.png 的构图——舷窗开在正对观众的舱壁上，而不是在两端舱门上或视线死角里），观众第一眼就要被"小舱室 + 大地球"的对比击中。

**风格定义：** 低多边形微缩模型风 + 细腻贴图：几何简洁、棱角分明、比例略 Q（设备稍微圆润敦实），但每个表面都有真实的材质细节——金属舱壁的铆钉与接缝、织物睡袋、屏幕像素、书脊纸面、植物叶片。**不要三渲二描边，不要写实 PBR 反光，不要塑料感。** 氛围：安静、治愈、有一点孤独感的浪漫——一个人住在距离地球 400 公里的轨道上，舱内是暖的，舱外是黑的，只有地球在舷窗里发着光。

**舱体结构：** 一个被纵向切开的胶囊形舱段（约 8×4 米、内高 2.5 米的尺度感），只保留后方弧形舱壁和舱内地板，舱壁和地板有厚度，切口处露出断面（断面里能看到夹层结构）。舱壁是圆角的金属板 + 铆钉 + 环形加强筋。**大圆形舷窗开在后方弧形舱壁的右侧 1/3 处**（带厚重窗框，直径约 1.5 米，从首屏等距视角直视可见，这是全场主角和构图锚点），左侧舱壁上有两扇小圆舷窗。舱内地板是防滑格栅板，中央嵌一条暖白灯带。舱段两端各有一个圆形舱门（关着，门上有小观察窗）。

**细节密度（硬性要求，以 style_ref.png 为及格线）：** 参考图的观感来自密度，不是来自单件精致。每个表面都要有三层细节——远景可见的二级细节：舱壁检修面板、铆钉阵列、警告标签与编号贴纸（如 "04"、"O₂"、"CAUTION"）、扎带固定的成束管线、通风栅格、磨损与使用痕迹；点击聚焦后可见的三级细节：织物经纬、纸面文字、叶片水珠、屏幕像素、杯身反光。舱壁不允许出现大面积"空白光板"——目视任何一块 1×1 米的舱壁，上面至少有 3 个细节件（面板/标签/管线/铆钉排/挂物）。零碎生活物的数量往参考图对齐：照片、便签、磁贴、笔、本子、杯子、工具、食品袋……摆到"有人真的住了半年"的程度。

**陈设（按区域，要摆得像有航天员真住在这里）：**
- 睡眠区（左端）：一个挂在舱壁上的立式睡袋（拉链半开，露出里面的枕头），旁边一块小隔板，上面用胶带贴着几张家人照片和一张手写的便签，一盏小小的阅读灯（亮着暖光）
- 工作区（右墙大舷窗下方）：一张折叠工作台，台上一台笔记本电脑——屏幕亮着，是轨道参数监控界面（深色背景、蓝绿色数据曲线和数字，能看出是航天数据）；一副挂着的降噪耳机、一个用魔术贴粘在桌面的保温杯、一支笔**漂浮**在桌上方缓缓打转、一本翻开的技术手册也漂浮着、几页用夹子固定在舱壁的图纸
- 观景位（大舷窗正前方）：一个可以半躺的固定座椅，正对着大舷窗，扶手上有一个控制面板（几个发光按钮），这是"看地球"的专属位置
- 绿植角（左墙小舷窗之间）：一个小型水培种植架，两三层，每层种着绿油油的生菜/罗勒，架子顶部一排粉紫色植物生长灯（亮着，是舱内第二光源），叶片上有水珠
- 健身角（右端舱门旁）：一台固定在地面的动感单车，把手缠着吸汗带，上方舱壁挂着一条毛巾
- 储物与零碎：舱壁上一排尼龙网兜储物袋（里面塞着食物包装袋、工具、一个魔方）；舱顶挂着几件用粘扣固定的衣物；一个灭火器和急救箱固定在舱壁；地板上有魔术贴拖鞋；各种管线沿舱壁走线、扎带整齐；设备面板上指示灯闪烁
- 漂浮小物件（这个 case 的灵魂之一）：舱内空气里慢速漂浮着——一支笔、一本书、一副无线耳机、一颗从种植架飘出来的小水珠、一块饼干碎屑，各自缓慢翻滚漂移

**光照与氛围（这个 case 的核心，必须做出"眩晕瘫坐"感）：** 大舷窗外是**地球**——弧形的地球占据舷窗画面的大部分，能看到大气层蓝色边缘光、云层、海洋、陆地。舱段在轨运行，**每 90 秒经历一圈完整的昼夜交替**（把真实 90 分钟压缩成 90 秒）：地球向阳面时，刺眼的阳光从舷窗涌入，在舱内投出清晰锐利的圆形舷窗光斑，舱内被照得通亮；飞入地球阴影后，阳光消失，窗外换成地球夜景——大陆上金色的城市灯光带像血管一样蔓延，舱内只剩暖色的舱内照明和植物灯的粉紫光，以及地球反照的一点点蓝色冷光洒在舷窗窗框上。阳光涌入的那几秒是整个作品最高光的时刻，要亮得"晃眼"、亮得让人眯起眼睛。舱内主照明是暖白灯带；睡眠区阅读灯、植物生长灯、设备指示灯是点缀光。冷（地球蓝、植物灯紫）vs 暖（舱内灯带、阳光）的对比是整幅画的基调。**两个"定妆画面"都必须成立**：昼——阳光从舷窗涌入，光斑锐利、舱内通亮、画面高光偏暖白；夜——舱内只剩暖黄阅读灯、笔记本屏幕光和植物灯粉紫，舷窗厚重的窗框上落着一圈地球反照的冷蓝边光，冷暖交界清晰可见，暗部沉得下去但不死黑。

**材质（硬性要求，不是按需取用）：** 各处表面必须用生图贴图做细腻的材质，不允许纯色糊过去：金属舱壁（哑光白烤漆 + 细微划痕与接缝）、地板格栅、睡袋织物、工作台面、屏幕内容（轨道监控界面，数据曲线清晰可读）、照片与便签、种植架金属与叶片、魔术贴与织带、管线包裹层。文字都要清晰不糊。地球用等距柱状投影贴图（云层、海洋、陆地、夜景城市灯光两张：白天面与夜晚面），地球大气层边缘要有发光的蓝色辉光。

**动效（持续、克制）：** 漂浮物（笔/书/耳机/水珠/饼干屑）缓慢翻滚漂移，永不停止、互不碰撞；笔记本屏幕上的数据曲线缓慢滚动；植物生长灯极轻微地呼吸；设备指示灯按各自节奏明灭；睡袋拉链头轻微晃动；地球在舷窗里缓缓移动（舱段在飞）；城市灯光带随地球转动缓缓流过舷窗。

**镜头：** 正交等距视角，可拖拽旋转（限制在能看清舱内的角度范围内）、缩放；首屏是标准等距角度。

**交互（这个 case 的重点之一，要做得顺手又浪漫）：**
- **点击聚焦**：点舱内任意主要物件（工作台、睡袋、种植架、观景座椅、健身车……）→ 镜头平滑拉近聚焦到它，方便看细节；点空白处或再点一次 → 回到等距全景
- **时间轴拖动**：按住大舷窗里的地球左右拖动 → 手动控制轨道时间，快进到阳光涌入的那一刻，或停在地球夜景最美的角度；松手后从该时刻继续自动流转
- **点大舷窗**：切换"快进模式"——昼夜循环加速到 15 秒一圈，地球光影在舱内快速扫过（这是录屏传播的爆点时刻）；再点一下恢复 90 秒
- **捡漂浮物**：鼠标靠近漂浮的笔时，笔像被气流扰动一样轻轻躲开一点；点它一下，它滴溜溜转起来
- **植物灯**：点一下关闭（绿植角暗下来，舱内氛围立刻不同），再点一下打开
- **舱内灯带**：点一下切换到"夜航模式"——主灯带熄灭，只留阅读灯、屏幕光、指示灯和舷窗外的地球光，整个舱段沉在静谧的蓝黑里；再点一下恢复
- 默认状态：自动 90 秒昼夜循环、灯带开、植物灯开、漂浮物在漂

**风格参考：** 本文件夹 `style_ref.png` 是氛围参考图——等距构图（舷窗+地球正对观众、占据视觉重心）、胶囊舱剖切形态、配色、冷暖对比、模型盒质感、**细节密度**全部以它为准（元素布局不必逐一对齐，陈设以本文描述为准）。自检时直接对照：把首屏截图和 style_ref.png 并排看，如果第一眼密度感、氛围感明显不如参考图，就继续加细节、调灯光，直到同一量级。

**地球贴图素材：** 本文件夹 `earth_day.png` 和 `earth_night.png` 是已生成好的地球等距柱状投影贴图（2048×1024，白天面/夜晚面两张，大陆分布一致，可直接做昼夜过渡混合）——优先直接使用这两张；贴上球体后检查左右接缝与极点拉伸，不满意再按 ai-texture 的 equirect 规范重新生成（2:1、地平线垂直居中、左右无缝）。

**实现分工：** 舱内一切必须是 3D 实体；大舷窗外的地球必须用 3D 球体 + 等距柱状投影贴图（白天/夜晚两张）实现，不允许用平面背景图糊过去；小舷窗里看到的也是同一个地球的不同角度。地球大气层边缘辉光、阳光光斑用着色器/光效实现。

**流程（分件确认，每步等我确认后再继续）：** 先分件做、各截一张图给我检查：① 舱体结构（弧形舱壁、地板、大舷窗、舱门、断面）+ 大舷窗外的地球（白天面）+ 阳光涌入的光斑 ② 工作区与观景位（屏幕要亮、漂浮物要有）③ 睡眠区、绿植角、健身角与储物零碎。我确认后再组装、补动效与交互、调昼夜循环。

**分工建模（派子 agent）：** 上面分件确认里的每一组各派一个子 agent 去做——每个子 agent 对自己那组里的每一件物品逐个精细化建模、生成贴图、自己截图自检达标后再交付；你负责先定统一规格（尺度、落位、风格、材质路线），再集成、做整体自检，然后按上面的流程和我分件确认。协作方式按 threejs skill 的分件协作规范。如果你的运行环境不支持派子 agent，就由你自己按同样的分工逐组完成。

**产物：** 一个能直接部署打开的网页；另外五张定格大图（首屏等距全景-地球白天面 / 首屏等距全景-地球夜晚面城市灯光带 / 点击聚焦到工作区 / 夜航模式 / 快进模式阳光扫过舱内的瞬间）。

**视觉自检（硬性要求）：** 过程必须包含视觉自检：按 threejs skill 的规范做截图自检，自己读图——①首屏构图：舷窗+地球是否直视可见、是否视觉重心；②细节密度：与 style_ref.png 并排对比，密度是否同一量级，舱壁有无"空白光板"；③昼夜两种光照各自的氛围、冷暖交界是否成立；④阳光光斑是否锐利真实、地球贴图是否清晰（云层/城市灯光带）；⑤贴图细节、文字是否清晰、漂浮物的位置是否自然。每个交互状态（聚焦 / 快进 / 夜航 / 捡漂浮物）都要截到，不满意就调整重来。
