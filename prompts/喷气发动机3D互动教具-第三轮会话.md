请基于当前「KIMI 立体课本 · 喷气发动机实验台」项目，仅优化手机端适配。



最高优先级要求：



1\. 桌面 Web 端必须保持当前效果，不得改变现有布局、尺寸、位置、样式和交互。

2\. 不要修改现有 Three.js 发动机模型、材质、灯光、动画、相机初始构图和教学逻辑。

3\. 不要重构或重写项目。

4\. 所有新增布局样式必须限制在移动端媒体查询内。

5\. 桌面端与移动端共用功能逻辑，但移动端可以有独立的 UI 展示方式。

6\. 修改完成后，必须对比确认 1280×720 和 1440×900 桌面端没有视觉回归。



一、适配范围



仅当满足以下条件时启用移动端布局：



```css

@media (max-width: 768px) {

&#x20; /\* 所有手机端新增和覆盖样式放在这里 \*/

}

可以增加更小尺寸和横屏断点：

@media (max-width: 430px) {

&#x20; /\* 小屏手机微调 \*/

}



@media (max-width: 768px) and (orientation: landscape) {

&#x20; /\* 手机横屏微调 \*/

}

不要修改桌面端原有 CSS 规则。不要把桌面端现有固定尺寸改成全局响应式尺寸。如果必须新增 class，请保证它在大于 768px 时不影响任何元素。

二、手机端整体布局

页面不能出现横向滚动条：

html,

body,

\#root {

&#x20; width: 100%;

&#x20; max-width: 100%;

&#x20; overflow-x: hidden;

}

如果上述全局规则可能影响桌面端，则将相关覆盖限制在移动端媒体查询内。

手机端使用 100dvh 适应浏览器地址栏变化。



Three.js Canvas 仍然铺满手机视口。



在手机视口变化和横竖屏切换时，正确更新：

renderer 尺寸

renderer pixel ratio

camera aspect

camera projection matrix



手机端单独调整发动机的初始镜头距离和画面中心，使发动机主体完整可见，并为上下浮层预留空间。



这些手机端相机参数不能影响桌面端相机和当前桌面端构图。



三、手机端标题区域

仅在手机端：

压缩标题区域高度和间距。

页面左右边距改为 14–16px。

主标题使用：

font-size: clamp(20px, 6vw, 28px);

副标题和章节说明使用约 12–13px 字号。

长标题允许换行，不得超出屏幕。

EN 按钮保持在右上角，点击区域不小于 44×44px，不能与标题重叠。

桌面端标题的字号、间距、位置和 EN 按钮必须保持现状。

四、增加手机端提示

仅在宽度小于或等于 768px 时，在标题区域下方显示轻量提示：

“建议使用电脑端打开，获得更完整的 3D 交互体验。”

要求：

桌面端不渲染或完全隐藏该提示，不得占位。



不要使用阻塞式弹窗。



使用现有视觉风格：

深色半透明背景

米白色文字

青蓝色或金色细边框

圆角 4–6px

字号 11–12px

不使用红色警告样式



右侧增加关闭按钮“×”。



关闭按钮点击区域不小于 36×36px。



添加：



aria-label="关闭电脑端体验提示"

使用 sessionStorage 保存本次浏览关闭状态，关闭后本次浏览不再重复显示。

提示不能遮挡发动机和主要操作区域。

五、手机端控制面板

当前桌面端左侧 .control-desk 必须保持现状。

仅在手机端，将 .control-desk 展示为底部抽屉：

默认收起，只显示一个紧凑控制条：

文案：“打开实验控制台”

显示当前状态，例如：“停机 · 油门 0%”

高度不小于 48px



展开后的布局：



position: fixed;

left: 12px;

right: 12px;

bottom: calc(12px + env(safe-area-inset-bottom));

width: auto;

max-height: 54dvh;

抽屉顶部固定显示：

“实验控制台”

“收起”按钮



内部内容区域独立滚动，不能带动整个页面滚动。



按钮最小高度 44px，相邻按钮间距不小于 8px。



滑块需要增加触摸区域。拖动滑块时不能触发页面滚动或 Three.js 模型旋转。



展开和收起不能重置以下状态：

启动 / 停机

油门

高度

爆炸程度

剖切

机匣透明度

气流模式

当前视角和章节



六、手机端站位信息

当前桌面端右侧 .engine-readout 必须保持现状。

仅在手机端，将站位信息改为可折叠浮层：

默认收起，只显示一个按钮：

“站位数据 · 0 进气”



按钮需要避开标题、EN 按钮和电脑端体验提示。



展开后：



left: 12px;

right: 12px;

width: auto;

max-height: 38dvh;

顶部固定显示当前站位和“收起”按钮。



推荐使用：

顶部为横向滚动的 0、1、2、3、4、8 站位标签

下方只展示当前选中站位的详细数据



不能让六张完整信息卡同时占满手机屏幕。



切换或收起信息浮层时，不得清除当前站位，也不得破坏现有的模型高亮、镜头定位和数据联动。



七、手机端面板互斥

仅在手机端：

控制面板和站位信息卡分别维护状态：

isControlPanelOpen

isReadoutOpen

两个面板默认都收起。



打开控制面板时自动收起站位卡。



打开站位卡时自动收起控制面板。



桌面端不使用这套互斥逻辑，保持当前两张卡片同时展示的状态。



八、手机端触控

仅在手机端或 pointer: coarse 设备启用：

单指拖动：旋转模型

双指缩放：调整镜头距离

操作按钮、滑块和面板时，不得触发模型旋转

限制镜头最近和最远距离

防止模型缩得过小或相机进入模型内部

横竖屏切换后重新计算 Canvas 和镜头，但不重置已有实验参数

九、免责声明和安全区域

仅在手机端，将免责声明缩短为：

“教学示意模型，数值不用于工程设计或安全计算。”

要求：

使用 10–11px 字号，最多两行。

避开底部控制条和 Kimi Agent 浮层。

使用：

env(safe-area-inset-bottom)

不得被 iPhone 底部操作区域遮挡。

桌面端保留当前完整免责声明及其当前位置。

十、动画与无障碍

手机端面板动画控制在 180–240ms。

优先使用 transform 和 opacity，避免明显掉帧。

支持：

@media (prefers-reduced-motion: reduce)

展开 / 收起按钮添加：

aria-expanded="true/false"

aria-controls="对应面板ID"

不要只依赖 hover 状态。
