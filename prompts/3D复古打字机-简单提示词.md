用 Vite + React + TypeScript + Three.js(@react-three/fiber) + Zustand + docx 从零构建一个名为「THE IMPACT No. 01 — 一台机械文稿编辑器」的全屏 3D 网页应用：不加载任何外部模型/贴图/音频，纯程序化几何体搭出完整打字机（机架、四行键帽、键杆、连杆、字篮与逐字字杆、色带卷轴与提升器、逃逸轮与棘爪、滑架滚筒压纸杆边距铃发条鼓、A4 纸），视觉为近黑背景 #070605 加暖色聚光的电影级机械陈列感，配色仅用 bone #e8e0cc / nickel #b08d57 / ink #070605，字体 Courier Prime + Georgia，界面为细边框直角大字距的极简控制台，禁止圆角渐变玻璃拟态。



实现真实的机械打字链路：敲键后按 键帽下沉→键杆→连杆→字杆上扬→色带抬起→100ms 撞击落字→逃逸释放→滑架进一格→字杆归位 的时序（全程约 240ms，回车约 720ms）联动，文稿状态机严格为每页 44 行 × 每行 72 列、第 66 列鸣铃、满行拒字、退格只移光标形成叠印、Enter 触发机械回车、页满需换新纸，落字用「页/行/列/字符」确定性伪随机生成墨色与 ±0.4px 抖动，绘制到 1488×2104 的 CanvasTexture 纸面（含纤维噪点与边缘暗化），并支持撤销/重做/清空确认/localStorage 草稿恢复。



配套功能：0–100% 爆炸拆解滑杆（>8% 时禁止书写并顶部提示）、剖视透明外壳、书写/机芯/检视三档平滑相机、检视模式射线点击零件弹出中英零件卡与「慢速追踪这次击键」2.6 秒传动链高亮、Web Audio 纯合成的按键/连杆/撞击/逃逸/铃/回车/纸张十余种音效开关、可选的 Unicode 输入法适配器（隐藏 textarea + 合成预览，中文经虚构字杆落纸）、自动回车与示例文稿、浏览器端 DOCX 导出抽屉（按机械页分页、Courier Prime、叠印可选保留策略）。



界面默认中文（lang="zh-CN"，首屏文案「在文字成为数据以前，它首先是一次撞击。」），右上角一键切 EN 且语言存入 localStorage；源码按 app/scene/machine/document/audio/ui/export 分目录拆分并用统一事件总线驱动，适配 1280×720 桌面与 390×844 移动端（面板贴底可滚、pixelRatio ≤1.5），支持 aria/prefers-reduced-motion 与 WebGL 不可用时的暗色降级页，最终须 npm run build 零错误通过。
