# 任务：制作 Bloomberg Terminal × ASCII 风格的全球股市监控 Canvas	
	
请直接制作并交付一个完整、可运行、可下载的交互式全球市场监控网站。重要输入边界：你不会获得任何现有产物、参考图、截图、录屏、网页、HTML、CSS、JavaScript、源码、设计文件或 Skill；我最终只会给你本 Prompt，并可能提供股票、指数、贵金属、市场时段或新闻等原始研究数据。必须仅依据本 Prompt 中完整的视觉、布局、数据、交互与验收规格从零实现，不得要求补充原产物。目标视觉是黑底、高信息密度、Bloomberg 橙色命令栏、等宽字体、窗口化模块、热力图 + 行情 + 新闻线；不得只做静态图片，也不得照搬 Bloomberg 商标或受保护图标。	
	
直接完成成品、实际运行和测试，并交付可下载压缩包。不要只回复方案、线框图、伪代码或零散代码。	
	
## 1. 产品定位	
	
这是一个可长期打开的“全球股市与新闻监控工作台”，核心不是漂亮留白，而是：	
	
- 在一屏内同时观察全球指数、AI/科技、能源、金融板块的涨跌结构；	
- 追踪 AAPL 60 个交易日的价格与成交量；	
- 监控 XAU/XAG/XPT/XPD 四种贵金属及其相对关系；	
- 查看上海、香港、东京、伦敦、纽约等市场当前是否开市以及下一次切换时间；	
- 通过 News Wire 将行情变化与带时间戳的新闻连接；	
- 像 Canvas 一样拖动、缩放、重排、增删模块，并持久化布局。	
	
它应该像 Bloomberg Terminal、ASCII 终端和专业交易台的结合，而不是消费级股票 App、普通管理后台或带巨大圆角卡片的 SaaS Dashboard。	
	
## 2. 强制视觉系统（无需任何参考图）	
	
### 色彩	
	
- 主背景：纯黑到近黑 `#000000` / `#050505`；模块背景仍接近黑，不使用蓝灰大底。	
- 主文字：灰白 `#D7D7D7`；次级信息 `#8A8A8A`；网格与分隔线 `#292929` / `#3A3A3A`。	
- 命令栏、模块标题条、焦点态：使用 Bloomberg 风格但不含其商标的橙色 `#F28C00` 或相近琥珀橙；标题条采用橙底黑字或黑底橙字，保持高对比。	
- 上涨：终端绿 `#00C176`；下跌：警示红 `#FF4D4F`；中性/未开盘：灰；选中/信息：琥珀或冷青，但不能形成彩虹色。	
- 颜色含义全站一致；涨跌同时使用 `+/-`、箭头或符号，不只靠颜色。	
	
### 字体与细节	
	
- 全站主要使用本地打包的等宽字体，例如 IBM Plex Mono / JetBrains Mono / Menlo 等；标题可使用更窄的等宽粗体。	
- 字号紧凑：正文约 11–13px，数字列对齐，表格使用 tabular numbers。	
- 模块为硬边窗口，0–2px 圆角，1px 细边框；禁止玻璃拟态、阴影浮卡、大片渐变、霓虹光晕和超大留白。	
- 图表线条细而锐利；坐标、刻度、单位、图例、来源和 `as-of` 必须清楚。	
- 可用少量 ASCII 字符、方框、十字准星、`>` 命令提示、`[F1]` 快捷键提示、扫描游标和分隔线强化终端感，但不得影响阅读。	
	
### 顶部命令区	
	
- 顶部保留 28–36px 的橙色/黑橙命令栏，显示产品名、当前时间、数据模式、连接状态和快捷命令。	
- 第二行是全球 ticker tape，横向显示主要指数/资产：S&P 500、NASDAQ、Dow、STOXX 50、FTSE 100、Nikkei 225、Hang Seng、SSE Composite，以及 XAU、WTI、DXY 等；每项含 Last、Change、Change%。	
- ticker 可自动缓慢滚动，也可暂停；减少动态模式下改为静态分栏。	
	
## 3. Canvas 布局与窗口系统	
	
- 使用 12 列桌面栅格，默认 1440×900 时尽量在一屏展示主模块，允许纵向滚动查看第二屏。	
- 每个模块都有窄标题条、模块编号/快捷键、数据时间、最小化、放大、拖动手柄和删除按钮。	
- 支持拖拽重排、改变宽高、网格吸附、碰撞处理、置顶/锁定；操作时显示精确的占位轮廓，不能出现重叠或越界。	
- 提供 `EDIT LAYOUT` 模式；普通浏览状态避免误拖。	
- 提供 `ADD WIDGET` 菜单，可恢复被删除模块；提供 `RESET DEFAULT` 和布局预设：`GLOBAL / EQUITIES / METALS / NEWS`。	
- 布局、模块显隐、尺寸、排序、筛选和时区保存在 `localStorage`，刷新后恢复。数据模式改变时不要覆盖用户布局。	
- 可选实现“桌面固定/独立窗口”能力；若浏览器权限不支持，明确提示，不得报错。	
- 移动端不启用自由拖拽，改为可排序的单列/双列堆叠；无水平溢出。	
	
## 4. 必做模块	
	
### A. GLOBAL TICKER / 全球行情带	
	
- 显示上述主要指数与资产的 Last、Change、Change%、状态和 `as-of`。	
- 使用固定列宽和滚动/分页，不因数字位数变化造成抖动。	
- 点击任一项目可将其设为焦点资产，并联动图表或打开详情 Inspector。	
	
### B. STOCK TRACKING：AI / TECH / ENERGY / FINANCIALS 热力矩阵	
	
- 这是主视觉模块，必须采用矩形 heatmap/treemap，并占据默认桌面布局最大面积。	
- 至少包含三个板块组：AI/Tech、Energy、Financials；可加入合理子行业，但不要使页面失焦。	
- 每个股票块显示 ticker、公司简称、Last、Change%；上涨绿、下跌红，颜色深浅映射涨跌幅绝对值。	
- 面积映射必须可切换且明示：默认可用 `|CHG%|`；如果获得成交额/市值等可靠数据，可提供 `MARKET CAP / TURNOVER / |CHG%|` 按钮，不能让面积含义不明。	
- 组间有清楚边界和标题；极小方块仍可 hover/click，必要时用列表降级。	
- 顶部筛选：`ALL / AI-TECH / ENERGY / FINANCIALS`；支持搜索 ticker。	
- hover 显示快速行情；click 固定到 Inspector，显示 Open、Prev Close、High、Low、Volume、Market Cap（若有）、来源和时间。	
	
### C. MARKET BREADTH SUMMARY	
	
- 紧凑摘要行显示：上涨数、下跌数、平盘数、涨跌比、当日 Top Gainer、Top Loser、最活跃板块。	
- 统计必须基于当前筛选的股票集合；明确样本数，不能暗示代表整个市场。	
- 点击摘要项联动筛选热力图。	
	
### D. SECTOR INTRADAY：板块日内走势	
	
- 展示 AI/Tech、Energy、Financials 三条板块平均/指数化日内 mini-series。	
- 每条序列归一化为 24 个采样点或实际可得的等间隔点，明确基准（例如开盘=0%）。	
- 同时给出板块平均涨跌条形图，标注平均方法（等权/市值加权）和样本数。	
- 不同交易时区的数据不得伪装成完全同步；闭市市场显示闭市状态和最后更新时间。	
	
### E. NEWS WIRE	
	
- 紧凑新闻线按时间倒序显示：`HH:MM:SS / 分类 / 标题 / 来源`。	
- 分类至少覆盖 `AI / TECH / ENERGY / FINANCE / MACRO / METALS`。	
- 提供分类筛选、关键词搜索、暂停自动更新、未读标记。	
- 点击新闻在侧边详情显示完整摘要、原始链接、来源、发布时间、涉及 ticker 和相关行情变化。	
- 不得虚构新闻；无实时新闻权限时进入 DEMO 模式，并把所有演示新闻显著标为 DEMO。	
	
### F. AAPL 60-SESSION PRICE & VOLUME	
	
- 主图展示 AAPL 最近 60 个有效交易日，不是 60 个自然日。	
- 价格用终端绿细线/面积极弱填充；成交量用琥珀柱；共享 X 轴但使用清楚的独立刻度。	
- 顶部统计：Last、Delta、Delta%、Open、Previous Close、High、Low、Volume、52W Range（若可得）、`as-of`。	
- 十字准星 hover 显示日期、OHLC、Volume；支持键盘左右移动。	
- 不补齐周末和节假日；拆股/复权口径必须说明。	
	
### G. PRECIOUS METALS MONITOR	
	
- 四个紧凑报价块：XAU、XAG、XPT、XPD，显示 Last、Change、Change%、单位、报价币种、短 sparkline 和 `as-of`。	
- 选中一种金属后，下方展示 60 个有效交易日主图。	
- 同时计算并展示 Gold/Silver Ratio、Gold–Platinum Spread 和各资产 60 日区间；每项写清公式与单位。	
- 如果不同数据源的现货/期货口径不一致，不能直接混算；应禁用衍生指标并说明原因。	
	
### H. MARKET PULSE：全球开闭市时钟	
	
- 使用大型 ASCII/等宽数字时钟显示用户选择时区的本地时间、日期和 UTC 偏移。	
- 展示 SSE、HKEX、TSE、LSE、NYSE/NASDAQ 的状态：`OPEN / PRE / LUNCH / CLOSED / HOLIDAY / UNKNOWN`。	
- 每个市场显示当地时间、常规交易时段、下一次开/闭市倒计时。	
- 制作 24 小时横向 session map：各市场用条带显示交易窗口，竖直 `NOW` 线随时间移动。	
- 正确处理夏令时、跨日、午休和节假日；若没有节假日日历，不得把节假日误报为正常开市，应显示 `HOLIDAY STATUS UNVERIFIED`。	
	
### I. GLOBAL INDEX MAP / LIST	
	
- 用紧凑区域列表或终端式世界分区展示 Americas / Europe / Asia-Pacific 主要指数。	
- 每行显示指数、交易所、Last、Change%、状态、当地时间和 `as-of`。	
- 地图仅作导航，不使用失真面积表达涨跌；点击与 ticker/Inspector 联动。	
	
### J. DATA / SOURCE INSPECTOR	
	
- 点击任一股票块、行情、新闻、图表点、金属或市场状态后打开右侧 Inspector。	
- 至少显示：对象名称、精确值、单位/币种、日期时间和时区、数据源、`as-of`、live/demo 状态、原始链接、口径、可用字段、错误/延迟状态。	
- hover 仅预览；click 固定；支持关闭、Escape、焦点返回；移动端为底部抽屉。	
	
## 5. 数据架构与真实性	
	
优先通过 Kimi 可用的合法财经数据源/搜索能力获取真实数据，例如交易所、指数官网、公开行情源，以及可访问的恒生、标普、同花顺等来源。不得抓取需要绕过登录、付费墙或反爬限制的内容。	
	
实现两个清楚分离的数据适配器：	
	
1. `LIVE ADAPTER`：请求真实数据，统一为内部 schema；每个响应保留来源、时间、时区和错误状态。	
2. `DETERMINISTIC DEMO ADAPTER`：用于离线展示和接口失败，数据固定可复现，不使用随机数。	
	
规则：	
	
- 任何实时授权、接口或网络失败时，页面仍可用，但顶部与每个受影响模块必须显著显示 `DEMO DATA` 或 `STALE`；不得把缓存/演示值伪装成实时值。	
- 每个模块显示独立 `as-of`，不能只给全局时间。	
- 对交易日、时区、货币、复权、现货/期货、指数/ETF 做明确口径说明。	
- 提供 `DATA STATUS` 面板，列出每个 adapter 的状态、最后成功时间、延迟、错误和回退原因。	
- 缓存最后一次成功数据，并标记缓存时间；不因局部失败拖垮整页。	
- 绝不在源码中放密钥。需要密钥的 live 模式提供配置说明和环境变量方案；静态 `file://` 默认进入 DEMO。	
	
## 6. 技术与响应式要求	
	
- 最终交付可离线打开的静态网站，入口 `index.html`；解压双击即可进入完整 DEMO 模式。	
- 禁止运行时依赖 CDN、在线字体或远程图片；依赖、字体、图标和演示数据本地化。	
- 如 live 模式因浏览器 CORS 需要本地代理，可额外提供可选轻量服务和说明，但不得影响离线 DEMO 主交付。	
- 推荐原生 HTML/CSS/JS 或轻量本地框架；图表用 Canvas/SVG。保持快速首屏和稳定 60fps 拖拽。	
- 所有窗口在 1440×900、1280×800、1024px 和 390×844 下无重叠、裁切或水平滚动。	
- 键盘支持：Tab、Enter、Escape、方向键浏览图表、快捷键切换模块；焦点轮廓清晰。	
- ARIA 标签、数据表/文字摘要、足够对比度、`prefers-reduced-motion` 和色觉友好。	
- 不得存在 console error、404、`NaN`、未捕获 Promise、布局抖动、拖拽后丢失、占位文案或随机假数据。	
	
## 7. 默认桌面布局建议	
	
- 顶部：命令栏 + ticker tape，占全宽。	
- 第一主区左 8 列：Stock Tracking 热力矩阵；右 4 列：Market Breadth + News Wire。	
- 第二主区左 7 列：AAPL 60-session；右 5 列：Sector Intraday + Sector Average。	
- 第三主区左 7 列：Precious Metals；右 5 列：Market Pulse + Global Index List。	
- Inspector 从右侧覆盖/推挤，不破坏栅格。用户可自由重排，默认布局只是初始状态。
