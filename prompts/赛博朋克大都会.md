【三、赛博城市内容与视觉目标】	
1. 场景必须形成从街道、贫民窟、地铁、高架、屋顶平台、密集住宅到摩天楼的多层次巨型都市；参考源码以约 609 个 prefab、83 类材质、2774 个原始摆放，加上约 1267 个平台杂物和 1867 个城市带状填充组成高密度场景。无需机械复制数字，但最终城市必须在近景、中景、远景都连续丰富，鸟瞰时没有大片空洞。	
2. 关键视觉：橙粉黄昏天空、远处被雾吞没的城市轮廓、暗色楼体、数以千计的暖黄窗灯、白/青/红/粉高亮霓虹、巨大楼体广告、日文/英文/数字标识、管线、空调、屋顶设备、街边自动售货机、道路与高架。原产物视频中高速摆荡时仍能持续看到密集建筑和发光广告，不出现“只有出生点精细、远处是空地”的情况。	
3. 场景至少具有五类可用于验证的地标视角：街道起点、地铁区域、贫民窟、摩天楼区、全城鸟瞰。玩家必须能从街面到屋顶、再到高楼间持续穿梭。	
4. 使用 `data/materials.json`、`prefabs.json`、`scales.json`、`scene.json`、`sign_fixes.json`、`fbx_mat_order.json` 等数据驱动场景；几何按类别拆成 Background、Car、Combined_Building、Decals、Environment、Facade_Details、Metro、Modules、Street 等 Draco 压缩 GLB。若采用不同资源，也必须保持“数据清单 + 模型模板 + placement”分离，禁止在 main.js 手工写几千个对象。	
5. 坐标转换必须一致。若素材来自 Unity→Blender→glTF，统一使用镜像 X 的转换：位置 `(-x,y,z)`，四元数 `(x,-y,-z,w)`，scale 不变；先用地标和道路方向验证，避免城市整体镜像、模型旋转错误或角色朝向相反。	
6. 纹理优先 WebP，并由 `textures_webp.json` 判断回退 PNG；正确设置 sRGB/Linear、flipY=false、RepeatWrapping 与最大各向异性。Unity MetallicSmoothness 需将 R 通道映射到 metalness、Alpha 反转后映射到 roughness；法线、AO、透明/AlphaTest 和玻璃材质不能套错色彩空间。	
7. 去除 GLB 中 `LOD1+` 和 Collider 可视网格，避免多层 LOD 叠画、Z-fighting 和灰色碰撞壳。FBX 多材质必须按材质名称/Unity slot 映射而不是盲按 primitive 顺序，否则建筑外墙会被地面贴图覆盖。	
8. 同 prefab、同材质几何先合并，再使用 InstancedMesh 批量实例化；完全重复 placement 删除，同位置不同旋转层轻微抬高约 0.03m 防止共面闪烁；负缩放实例单独使用 DoubleSide。所有实例计算 bounding sphere。	
9. 处理原素材常见缺陷：将 UV 密度退化或超大水平三角面改为平面投影混凝土纹理；无支撑的地面贴花剔除；悬空建筑底座自动向下生成与城市混凝土一致的 foundation podium；漂浮广告吸附到最近真实立面；云粒子改为低透明度相机朝向 billboard，不能像混凝土板漂在空中。	
10. 城市内部未铺地的空洞要有与照片地毯/混凝土风格一致的可见安全底板，但地铁 y≈−20 至 −26 的真实地下空间仍可行走；安全底板不得进入普通可视碰撞网格导致蛛丝粘到虚空。	
	
【四、渲染管线、天空和氛围】	
1. `WebGLRenderer({antialias:true,powerPreference:'high-performance',logarithmicDepthBuffer:true})`；像素比上限 1.5；相机默认 75°、near 0.3、far 9000，足以容纳约 5.8km 城市且减少深度闪烁。	
2. 使用 ACESFilmicToneMapping；黄昏曝光约 1.08。使用场景自带的等距环境图生成 PMREM 环境反射，配合 HemisphereLight 与 DirectionalLight。不能用纯环境光照亮一切，街区应保留深暗面与霓虹层次。	
3. 使用跟随相机的程序化天空穹顶 Shader：顶点锁在远平面，片元实现天顶/地平线/地面渐变、太阳圆盘与 halo、五层 FBM 云、风向移动、星星闪烁、月亮。内置 Night/Day/Dusk 三套参数，T 键循环；默认进入菜单和游戏时为 Dusk。	
4. Dusk 视觉参数接近：天顶 #262a55、地平线 #f2a06a、太阳 #ffb27a、粉橙云、少量初现星星、雾色 #8d7f8e、指数雾密度约 0.0007；Night 有蓝黑天空/月亮/星星，Day 有蓝天白云与更低雾密度。切换时同步调整天空、雾、灯光、曝光、环境强度和 Bloom。	
5. 后处理使用 EffectComposer：RenderPass → UnrealBloomPass → OutputPass；优先 4× MSAA、HalfFloat render target。Dusk Bloom 可从 strength 0.6、radius 0.5、threshold 0.8 起调，让白灯/红灯/广告发光但不过曝糊屏。低性能模式降采样或关闭 MSAA/Bloom。	
6. UI 与 HUD 使用独立 DOM 层覆盖 Canvas；Canvas resize 时同步更新相机 aspect、renderer 和 composer。不要将文字绘到 3D Canvas 导致模糊。	
	
【五、角色、骨骼动画与蛛丝表现】	
1. 两名角色都是真实 SkinnedMesh：男角色迷彩夹克、战术背心、浅灰裤；女角色鸭舌帽、双肩包。使用 Draco GLB 与约 24 类角色材质，正确处理皮肤、衣物、眼睛/角膜透明度；不能用胶囊、纯色人形或静态 T-pose 代替。	
2. 必须加载并映射至少以下动画：Idle、Walk Forward、Run Forward、Sprint（可复用 Run 并 timeScale≈1.3）、Jump from Run、Jump Loop、Soft Landing、Landing Roll、Falling Loop、Swing Loop、Swing Release。过滤 scale 轨道以及除 pelvis 外的恒定 position 轨道，避免骨骼变形；Swing/Fall/JumpLoop/LandRoll 可移除 pelvis.position 防止 root motion 与物理位置打架。	
3. 状态机映射：ground 且速度<0.6=idle，<6=walk，<11=run，否则 sprint；air 上升=jumpLoop、下降=fall；swing=swing；wallrun/zip 暂用 fall 或对应专属动画。动画切换用 0.08–0.3 秒 crossFade。	
4. 落地冲击>15 触发约 1.15 秒翻滚落地；冲击>5 触发约 0.45 秒软落地。角色朝向平滑追随水平速度，不随相机瞬间打转。	
5. 蛛丝从对应手骨 `hand_l/hand_r` 发出。根据锚点相对移动方向的叉积自动选择左右手。蛛丝不是一条僵硬 Line：使用 6 段细圆柱沿二次贝塞尔曲线连接手与锚点，中点下垂 `0.6 + slack×14`，绳松时自然弯曲、受力时逐渐拉直，材质为略带自发光的灰白纤维。	
	
【六、输入与核心玩法——数值和状态必须连贯】	
1. 使用统一 Input 类维护 `keys`、`justPressed`、鼠标右键、yaw/pitch；keydown repeat 不重复触发跳跃/吐丝；窗口 blur 与 pointer lock 退出时清空按键，防止角色持续移动。鼠标锁定时灵敏度约 0.0023，pitch 限制约 −1.25～1.35。	
2. 操作表必须显示在首次进入或可随时查看：WASD 相机相对移动；鼠标转相机；Shift 地面冲刺/摆荡收绳；Space 地面轻按跳跃、空中长按发射并保持蛛丝、松开脱离；W 在摆荡低点泵速；A/D 摆荡转向；S 空中俯冲；E 或鼠标右键飞掠到瞄准的屋顶边缘；R 从高空重新跃入；T 切换昼夜；Esc/退出鼠标锁进入暂停，点击或 Enter 继续。	
3. 物理采用固定状态机 `ground | air | swing | wallrun | zip` 和半隐式 Euler，`dt` 最大夹到 0.05，禁止直接每帧给 position 加固定值。建议基准：步行 8.5m/s、冲刺 14m/s、跳跃初速 13m/s（冲刺额外约1.5）、空中重力 30、摆荡重力 26、空中加速度14、基础空速上限17、全局最大速度68m/s。	
4. 地面移动用指数阻尼追目标速度；高速落地保留部分水平动量。提供约0.12秒 coyote time；离开支撑面后才转 air，避免屋顶边缘抖动。	
5. 空中按住 Space 且离地超过约0.18秒后寻找锚点。锚点搜索半径约110m：先用空间哈希/AABB 广相位找玩家前上方高楼表面，再按高度、朝向、距离打分，只检查前10个候选；最终必须用真实几何 Raycaster 验证射线首次命中，锚点至少高于玩家7m、距离6–110m。抬高镜头应显著提高锚点上限，高速时适度混合前进方向与速度方向。	
6. 成功附着进入 swing：绳长初值约距离×0.96，下限3.5m，并限制摆荡最低点距街面。使用球形硬绳约束，但每帧位置纠正最大约28×dt，去掉向外径向速度，不能瞬移或凭空泵能量。	
7. 摆荡时 W 施加切向泵速（基准16，低点最强），A/D 施加左右操控（基准9），Shift 以约12m/s 收绳；空气阻力随速度缓增。松开 Space 时脱离，向上速度可乘约1.22但封顶34m/s，水平速度约×1.045，形成顺滑抛物线而非突然掉落。	
8. 空中按 S 且正在下降时进入俯冲，重力提高到约38，空气阻力更小；相机拉远/FOV增大。按 E/右键飞掠：在约115m内寻找与镜头方向夹角高度一致、align>0.80 的真实屋顶边/角，向内探测屋顶并检查路径无遮挡；以至少40m/s 拉向目标，约1.6秒超时或距目标<3m后退出，给一点向上速度。	
9. 墙跑由真实侧墙碰撞触发：玩家在 air、向墙速度>3.5、方向键持续压向墙面、垂直速度>−14时进入；沿墙上冲并受较小重力，最长约1.15秒。期间按 Space 用墙法线约11m/s + 向上11.5m/s + 前向4m/s 跳离；松开向墙输入、下落过快或超时结束。	
10. R 触发重新跃入：角色从城市街道上方约430m处，以轻微前向/下落速度进入，镜头朝详细主街；用约380ms浅蓝白闪屏和“重新跃入城市”提示。初次开始也从鸟瞰菜单镜头无缝过渡到高空俯冲，而不是瞬间切到地面。	
	
【七、碰撞、地面探测与防穿模】	
1. 从城市 InstancedMesh 构建世界 AABB，按 100m 网格做空间哈希；AABB 只用于广相位、相机遮挡和候选锚点，任何墙体推开、蛛丝锚点、飞掠落点必须再用真实几何 raycast 验证，避免 L 形建筑或跨空结构产生“空气墙”。	
2. 玩家碰撞体近似半径0.42m、高1.7m，0.5m以下台阶可自动上台。地面检测从上一帧高度向下投射，中心点 + 前后左右4个脚底探针覆盖接缝；只有本帧从上方跨越地面或小台阶时才落地，不能在低矮雨棚下被吸到棚顶。	
3. 高速水平移动需要 swept ray 防 tunneling：胸部每帧检测，膝/头交替30Hz检测；碰到真实墙面时回退到接触点并移除向墙速度。AABB 推开前在两个高度向内探测真实几何，无命中则判定为空心结构并穿过。	
4. 玩家在实体地面站立超过约0.5秒后记录 lastSafe。跌出世界（例如 y<−80，或 y<−32 且高速下坠）优先淡出并拉回最近安全点，显示“已拉回附近的安全点”；只有从未记录安全点时才重新高空跃入。不得出现每隔几秒无故从天上重开的问题。	
5. 不能把地铁区域误判为坠出世界；不能把未铺装街区当无限深空洞；站在屋顶边缘时探针不能把玩家吸到邻楼屋顶。	
	
【八、第三人称电影相机】	
1. 相机围绕角色头上约1.35m的观察点，加入速度向量×0.16的前瞻，前瞻最大约4.5m，并以指数插值平滑，避免高频抖动。	
2. 基础跟随距离约4.2m，随速度增加至约7.8m，swing 再增加约1.1m。相机必须使用 AABB segment 测试做遮挡拉近：遇墙立即拉近，离墙后较慢放远，最近距离约1.7m，禁止镜头穿楼。	
3. swing/zip 时缓慢自动把 yaw 对齐速度方向，但仍保留玩家鼠标控制。根据横向速度施加最大约±0.10rad镜头 roll；FOV 基础62°，高速逐渐到79°，俯冲额外约6°。所有变化用阻尼而非跳变。	
4. 菜单镜头在约398m高度以极慢速度绕高空出生点旋转并俯瞰黄昏城市；点击开始后用约1.5秒 smoothstep 从当前鸟瞰位置/四元数融合到跟随相机，完整保留“电影开场→高空下坠→自由穿梭”的连续感。	
	
【九、HUD、暂停与反馈】	
1. 左下角 HUD 为三个半透明深色玻璃小面板，圆角8px、细蓝紫边框、轻微 backdrop blur：速度（km/h）、高度（m）、状态。数值约20px，标签9px大字距；进入游戏后0.6秒淡入。	
2. 状态中文映射：ground=地面、air=空中、swing=摆荡、wallrun=墙跑、zip=飞掠。速度使用世界速度×3.6后取整，高度不小于0。

【十、性能、资源回收、响应式与可访问性】	
1. 目标桌面 1440×900/1920×1080 下中端独显稳定≥45fps，最低不低于30fps；大量城市物体必须依赖 InstancedMesh、按材质合批、视锥裁剪、纹理WebP/Draco、DPR上限、LOD/距离裁剪和后处理分级。菜单参考约200 draw calls、游戏复杂视角约250–400 draw calls，避免几千次 draw call。	
2. 加载完成后预热已加载纹理到 GPU，减少首次高空俯冲时卡顿；首屏资源按优先级加载，角色/近景/菜单先完成，远景和次要杂物可渐进加载，但不得在玩家面前突然大面积弹出。

4. `visibilitychange`、blur、pause 时暂停重型更新；resize 同步所有缓冲区。销毁/重新载入时 dispose geometry/material/texture/render targets、取消 RAF 和事件监听，不能累积 GPU 内存。

7. 捕获资源加载错误、WebGL context lost、Promise rejection；显示符合视觉的错误层和重试按钮。控制台不得持续刷错误或警告。
