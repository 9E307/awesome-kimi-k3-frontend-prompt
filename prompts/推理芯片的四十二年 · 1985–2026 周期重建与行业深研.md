## 1. 产品定位					
					
网站是一份围绕“推理芯片四十二年周期”的交互式研究报告，时间范围为 1985–2026 年。					
					
核心问题：					
					
```text					
2023–2026 年的推理芯片繁荣，是旧周期的再次上演，还是一轮受新约束驱动的新周期？					
```					
					
研究结构：					
					
- 用六个历史窗口重建 FPGA、定制 ASIC、云端加速器和 AI 推理芯片的发展					
- 比较需求点火、供应约束、重复下单、产能到达和行业出清的共同机制					
- 分析当前周期中的资本开支、TPU、Trainium、ASIC 渗透率、CoWoS、HBM、先进制程和电力约束					
- 压力测试“利润跟随芯片”“2027 年 ASIC 单位出货超过 GPU”“需求可见至 2028 年”三项共识					
- 给出两种情景、明确的失效阈值和八个季度监测触发器					
- 不提供买入、卖出、持有评级，不提供目标价

## 6. Cover 精确复刻

```html

  <canvas id="cover-canvas-w"></canvas>					
  <div class="cover-inner">...</div>

```					
					
三个 Canvas 对应三种封面模式，同一时间只显示一个。					
					
Canvas 必须：					
					
```css					
#cover-canvas,

  position: absolute;					
  inset: 0;					
  width: 100%;					
  height: 100%;					
}					
```					
					
不得设置 `width:58%`，不得添加全屏 radial-gradient 点阵背景。					
					
Canvas 初始化：					
					
```js					
const rect = canvas.getBoundingClientRect();					
const cssWidth = rect.width;					
const cssHeight = rect.height;					
const dpr = Math.min(window.devicePixelRatio || 1, 2);					
					
canvas.width = Math.round(cssWidth * dpr);					
canvas.height = Math.round(cssHeight * dpr);					
canvas.style.width = "100%";					
canvas.style.height = "100%";					
					
ctx.setTransform(dpr, 0, 0, dpr, 0, 0);					
```					
					
不要调用会把 `canvas.style.width` 改成 `1px` 或 backing-store 像素值的通用函数。

```css					
#cover {					
  position: relative;

  overflow: hidden;					
  background: #fff;					
  border: 0;
```					
