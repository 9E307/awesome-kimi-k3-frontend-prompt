章节结构、图表和其它样式。

【Bug 1：封面图形与标题文字重叠】

现状：三个封面模式的 canvas（js/cover.js 递归 die、js/cover-exploded.js 爆炸图、
js/cover-wire.js 蓝图走线）都把图形画在封面中央（如 cover.js 里
S.dx = S.w * 0.56; S.dy = S.h * 0.5，baseSpan 高达 min(w,h)×0.74），没有任何
文字避让，宽屏下图形直接压在左侧 kicker/标题/导语/chips 上。

修复要求（与英文原版一致）：
1. 图形整体右移，锚点放在封面右侧区域（约 68% 宽度、45% 高度处），绝不进入
   左侧文字栏。
2. 加「文字净空」机制：绘制前用 getBoundingClientRect 实测 .cover-inner 内
   文字栈（.cover-kicker、.cover-title、.cover-sub、.cover-lede、.cover-chips、
   .cover-anchor、#cover-mode）每个元素的盒子并换算成 canvas 坐标；文字右缘
   加 24–48px 余量、文字栈底部加约 14px 余量的区域为禁区，禁区内图形不绘制
   （或透明度平滑衰减到 0）。窗口 resize 时重新测量。
3. 三个模式都要做：
   - js/cover.js：die 中心从 0.56w/0.5h 右移到 ≈0.68w/0.45h，按禁区做逐 cell
     掩码，并收敛 baseSpan，保证动画任意帧都不越过文字右缘；
   - js/cover-exploded.js：构图中心从 0.60w/0.60h 右移，整个爆炸图只允许出现在
     .cover-lede 右缘以右、或文字栈底部以下；
   - js/cover-wire.js：网格与走线整体右移，x < 文字右缘+余量的区域不布线。
4. 窄屏（<720px）：文字栏占满整宽时，图形移到文字栈下方（#cover-mode 之下）
   的空白条带并进一步减淡；封面高度随内容自然增长，不裁切文字。
5. 参考实现可直接抓取英文原版对比移植（注意替换选择器：原版
   .cover/.subtitle/.lead/.cover-note/.cover-modes ↔ 中文版
   #cover/.cover-sub/.cover-lede/.cover-anchor/#cover-mode）：
   https://765dvagfhthwu.ok.kimi.link/js/cover.js
   https://765dvagfhthwu.ok.kimi.link/js/cover-exploded.js
   https://765dvagfhthwu.ok.kimi.link/js/cover-wire.js

【Bug 2：宽屏下正文贴左、数据面板贴右，中间大片空白】

现状：css/style.css 里 main 和 #appendix 都是
  width: 820px; margin-right: var(--railw);
这是按 1280×720 写死的（1280−460=820）。屏幕一宽，main 贴左缘、460px 的
#dash-rail 贴右缘，中间全空。

修复要求（与英文原版一致）：
1. main 和 #appendix 都删掉 width: 820px，只保留 margin-right: var(--railw)，
   让容器占满数据面板左侧的全部宽度。
2. 内容列保持现有 max-width 和 margin: 0 auto 不变（.prose 692px、.wide 800px、
   .wide.xl 924px），文字/图表会自动在「左缘到数据面板之间」居中，任何宽度下
   都不再有中间空白。1280×720 下可用宽度仍是 820px，几何与现状一致、不回归。
3. ≤1180px 断点行为不变（main width:100%、margin-right:0、#dash-rail 隐藏）。
4. 同步修改 SPEC.md §3「布局契约」：把 main 的契约从写死 width:820px 改为
  「不定宽 + margin-right: var(--railw)，1280×720 的几何由 1280−460=820 自然
   得出」，避免以后按旧契约改回去。
